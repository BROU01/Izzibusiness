# À propos d'Izzibusiness

Izzibusiness est une plateforme fitness moderne qui combine l'entraînement sportif, la gamification et les paiements mobile money pour créer une expérience engageante et motivante.

## Vision

Rendre le fitness accessible, ludique et connecté pour tous, grâce à une plateforme qui récompense la progression et simplifie les transactions.

## Fonctionnalités principales

### 🏋️ Programmes sportifs

- Programmes d'entraînement personnalisés
- Suivi de progression en temps réel
- Adaptation selon les objectifs de l'utilisateur

### 🎮 Gamification

- Leaderboard pour créer une saine compétition
- Jeux interactifs pour maintenir la motivation
- Système de points et badges

### 💰 Portefeuille mobile money

- Dépôts via Kkiapay, Beem, PawaPay
- Retraits sécurisés
- Historique des transactions

### 👨‍💼 Back-office admin

- Gestion complète des utilisateurs
- Administration des programmes
- Suivi des transactions

## Stack technique

- **Frontend** : Next.js 16 (App Router), React 19, TypeScript
- **Styling** : Tailwind CSS 4 avec un design system néobrutalisme
- **Backend** : Supabase (PostgreSQL + RLS)
- **Paiements** : Kkiapay, Beem, PawaPay
- **Communication** : Resend (email), Twilio (SMS)

## Design system

Le projet utilise un design system unique « Néobrutalisme × Paper-Newsletter » qui combine :

- Une esthétique brutale avec des bordures nettes et des ombres dures
- Une texture papier chaleureuse avec une grille millimétrique subtile
- Une typographie expressive (Fraunces + IBM Plex Mono)
