# À propos d'Izzibusiness

Izzibusiness réunit, pour les membres d'Afrique de l'Ouest, des formations pratiques,
des missions rémunérées, des jeux à mises réelles et un wallet Mobile Money.

## Principes

- Les montants affichés viennent tous de `src/lib/config.ts`.
- Aucune donnée inventée : pas de faux témoignages, de faux classements ni de faux chiffres.
- Tout mouvement d'argent passe par une fonction SQL atomique et non rejouable.

## Fonctionnalités

- **Formations** : programme guidé de 20 jours, catalogue, demandes d'inscription.
- **Missions** : publiées par l'équipe, rémunération annoncée, validation sur preuve.
- **Jeux** : Aviator, Spin & Win, Apple Fortunes, tirage côté serveur vérifiable.
- **Parrainage** : bonus quand un filleul règle son adhésion.
- **Wallet** : dépôts et retraits Mobile Money via PayDunya.
- **Administration** : comptes, paiements, retraits, jeux, missions, messages, annonces.

## Stack technique

- **Frontend** : Next.js 16 (App Router), React 19, TypeScript
- **Styles** : Tailwind CSS 4, design system néobrutaliste (`DESIGN.md`)
- **Backend** : Supabase (PostgreSQL + RLS)
- **Paiements** : PayDunya
